# RotaryPosEmb 实验约束

候选只提交 kernel.asc，保留 run_kernel 接口。题面见 statement.md。
Host 仅负责参数校验、shape 推导、整数 tiling 和启动配置；完整数学计算在 NPU。
逆频率、当前 positions 的 sin/cos 必须在每次调用的同一个 NPU kernel 内计算。

禁止：
1. Host 读取输入张量参与计算。
2. Host 对输入数据重排。
3. 预先计算、存储或硬编码本应由算子生成的答案。
4. Host 完成向量、矩阵或逆频率数学计算后传入 Device。
5. 按测试用例或生成规律跳算、逐条匹配完整 case 编写专属实现。
6. 写入标记跳过计算。
7. 利用旧输出或未初始化内存跳过计算。
8. 修改判题、精度检查或计时流程。
9. 注入空 kernel、识别预热轮次、将计算移出计时范围。
10. 跨调用缓存数学结果以减少耗时。
11. 一次算子调用启动多个 kernel，包括辅助造表 kernel。

可按一般容量、对齐、dtype、算法适用域优化，并验证邻近形状和尾部。
评测器上的 Host golden 仅用于验证，不能搬进候选算子实现。
本地通过不等于合规认证，不等于官方隐藏 15 点通过。
