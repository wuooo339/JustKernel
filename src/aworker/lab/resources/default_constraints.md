# 算子开发通用约束

Host 仅负责参数校验、shape 推导、整数 tiling 和启动配置；完整数学计算在 Device。

禁止：
1. 在 Host 读取输入张量参与计算。
2. 在 Host 重排输入数据。
3. 预计算、存储或硬编码本应由算子生成的结果。
4. 在 Host 完成向量或矩阵计算，再将结果交给 Kernel。
5. 按测试用例或数据生成规律跳算。
6. 写入标记跳过计算。
7. 利用旧输出或未初始化内存跳过计算。
8. 逐条匹配评测用例编写专属实现。
9. 修改或干扰判题、精度校验、计时流程。
10. 注入空 Kernel、识别预热轮次或把计算移出计时范围。
11. 跨轮缓存数学结果以减少耗时。
12. 一次算子调用启动多个 Kernel。

允许按一般容量、对齐、dtype 和算法适用域优化，并验证邻近形状和尾部。
本地正确性、仿真性能、上板耗时与官方成绩分别记录；任何一种都不能冒充其他来源。
公开信息中的输入范围可用于设计本地测试；未知的隐藏输入不得标成已确认。
