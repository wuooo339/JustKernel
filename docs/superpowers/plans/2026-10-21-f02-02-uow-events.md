# F02-02 Repositories, UnitOfWork, Events, and Outbox Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Add SQLite repositories for Cluster/Agent, an explicit UnitOfWork transaction, an append-only event store, and an idempotent outbox.

**Architecture:** `platform/persistence/` adapters use `sqlite3` and the F02-01 schema. `UnitOfWork` begins one transaction and exposes repositories/events/outbox; commit/rollback is explicit. Cluster/Agent updates use `version` optimistic concurrency.

**Spec:** `SPEC/08-persistence-and-events.md` §3, §6.

## Global Constraints

- One transaction per use case: aggregate writes + events + outbox commit together.
- Optimistic concurrency uses `WHERE id=? AND version=?`; stale writes raise a stable conflict error.
- Event rows are append-only; duplicate EventId is rejected.
- Outbox idempotency key prevents duplicate entries.
- No ORM, no old-code imports, no old tests.

## Interfaces

```python
def connect(path=":memory:", *, foreign_keys=True) -> sqlite3.Connection: ...
class ConcurrencyError(JustKernelError): code = "concurrency.conflict"

class ClusterRepository:
    def insert(self, cluster: Cluster) -> None: ...
    def update(self, cluster: Cluster, expected_version: int) -> int: ...
    def version(self, cluster_id: ClusterId) -> int: ...

class AgentRepository:
    def insert(self, agent: AgentInstance) -> None: ...
    def update(self, agent: AgentInstance, expected_version: int) -> int: ...
    def get(self, agent_id: AgentId) -> AgentInstance: ...
    def version(self, agent_id: AgentId) -> int: ...

class EventStore:
    def append(self, event: DomainEvent) -> None: ...
    def read_after(self, seq: int = 0, limit: int = 100) -> tuple[DomainEvent, ...]: ...

class OutboxEntry:
    id: str; cluster_id: ClusterId; kind: str; payload: Mapping[str, object]
    idempotency_key: str; available_at: int; attempts: int = 0

class OutboxRepository:
    def enqueue(self, entry: OutboxEntry) -> bool: ...
    def pending(self, now_ms: int, limit: int = 100) -> tuple[OutboxEntry, ...]: ...
    def mark_attempt(self, outbox_id: str) -> None: ...

class UnitOfWork:
    clusters; agents; events; outbox
    def __enter__(self) -> Self: ...
    def __exit__(self, ...) -> None: ...
```
