# F03-07 Application ACL, Ownership, and Idempotency Tests

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Add a cross-service application test suite proving role ACL, mentor ownership, and idempotent message/budget behavior.

**Architecture:** Test-only verification feature. It composes existing ACL/capability functions with `AgentService`, `MessageInbox`, and the budget ledger. If a gap is found, fix the owning module and add a focused regression test.

**Spec:** `SPEC/11-testing-and-quality.md` §5.

## Global Constraints

- Worker roles have no board read/write and no board tools.
- Consultant reads MentorBoard but cannot post to it.
- Optimizer cannot read test records or boards; tester cannot write source/commit candidates.
- Only supervisor can select best/write report; only mentor can assign/close workers.
- Mentor cannot assign/close another mentor's worker.
- Message dedupe is by MessageId; budget reserve/settle is idempotent.
- No real models/devices/network; no old-code imports.
