# F01-04 Agent and Role Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Implement the fixed role enum, skill reference, AgentInstance lifecycle, and worker/mentor invariants.

**Architecture:** Pure domain modules under `src/justkernel/agent/`. No runtime, model, platform, or I/O imports. The aggregate is mutable with explicit transition guards; terminal state is `CLOSED`.

**Spec:** `SPEC/04-domain-model.md` §4.2; `SPEC/05-agent-runtime-and-skills.md` §2.

## Global Constraints

- Roles: `SUPERVISOR`, `CONSULTANT`, `MENTOR`, `OPTIMIZER`, `TESTER`, `PROFILER`.
- Worker roles (`OPTIMIZER`, `TESTER`, `PROFILER`) require exactly one mentor.
- Non-worker roles must not have a mentor.
- One agent has at most one running task/turn.
- Closed agents cannot receive new tasks/turns.
- Interrupted agents resume only with a new session.
- No old-code imports or old tests.

## Interfaces

```python
class Role(StrEnum):
    SUPERVISOR = "SUPERVISOR"
    CONSULTANT = "CONSULTANT"
    MENTOR = "MENTOR"
    OPTIMIZER = "OPTIMIZER"
    TESTER = "TESTER"
    PROFILER = "PROFILER"

WORKER_ROLES: frozenset[Role]

class AgentState(StrEnum):
    CREATED = "CREATED"
    IDLE = "IDLE"
    RUNNING = "RUNNING"
    FAILED = "FAILED"
    INTERRUPTED = "INTERRUPTED"
    CLOSED = "CLOSED"

class SkillRef:
    name: str
    version: str
    source_path: str
    digest: Digest

class AgentInstance:
    id: AgentId
    cluster_id: ClusterId
    role: Role
    mentor_id: AgentId | None
    model_profile: str
    skills: tuple[SkillRef, ...]
    created_at: int
    state: AgentState = CREATED
    session_id: str | None = None
    checkpoint_ref: str | None = None
    current_task_id: TaskId | None = None
    closed_at: int | None = None

    def initialize(self) -> None: ...
    def start_turn(self) -> None: ...
    def finish_turn(self) -> None: ...
    def start_task(self, task_id: TaskId) -> None: ...
    def complete_task(self) -> None: ...
    def interrupt(self) -> None: ...
    def resume(self, session_id: str) -> None: ...
    def fail(self) -> None: ...
    def close(self, now_ms: int) -> None: ...
```
