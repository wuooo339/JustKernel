# F00-05 CI Gates Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a GitHub Actions workflow that runs the same checks as the local feature workflow on Linux, macOS, and Windows.

**Architecture:** The workflow uses `astral-sh/setup-uv`, installs from `uv.lock`, runs ruff, mypy, pytest, and `uv build`. It has no legacy checkout, no old test suite, and no external device dependency.

**Spec:** `SPEC/11-testing-and-quality.md` §9.

## Global Constraints

- Python 3.13, locked dependencies, no secrets.
- CI must fail on lint/format/type/test/build errors.
- No `aworker` checkout or old test command.

## Steps

- [ ] **Step 1: Add the workflow**

```yaml
name: checks
on: [push, pull_request]
permissions:
  contents: read
jobs:
  test:
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v6
        with:
          python-version: '3.13'
          enable-cache: true
      - run: uv sync --locked
      - run: uv run ruff check src tests
      - run: uv run ruff format --check src tests
      - run: uv run mypy src/justkernel
      - run: uv run pytest -q
      - run: uv build
```

- [ ] **Step 2: Verify the same commands locally**

```bash

```
