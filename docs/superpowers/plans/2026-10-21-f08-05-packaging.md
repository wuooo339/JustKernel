# F08-05 Packaging, Dependencies and Supply-Chain Checks

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Make wheel/sdist contents, runtime dependencies and entrypoints deterministic and fail-closed, excluding local agent/index state.

**Architecture:** Hatch wheel packages `src/justkernel`; sdist whitelists package/tests/project files and excludes agent/index/ephemeral paths. `scripts/check_dist.py` validates archives and dependency metadata; CI runs it after `uv build`.

**Spec:** `SPEC/12-migration-and-acceptance.md` §5; `SPEC/11-testing-and-quality.md` §9.

## Global Constraints

- Wheel contains only `justkernel` + dist-info.
- sdist contains only the project prefix and whitelisted files.
- No `.codegraph`, agent config, env/secrets or temporary files.
- Runtime dependencies are exactly `fastapi`/`pyyaml`.
- Entry point is only `justkernel`.
- No old package names.
- No old-code imports/tests.
