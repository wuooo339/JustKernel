# F02-01 Journal Schema and Migrations Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Create the cluster journal SQLite schema with ordered migrations, partial unique indexes, foreign keys, and append-only event triggers.

**Architecture:** `platform/persistence/schema.py` holds idempotent SQL DDL; `migrations.py` runs ordered migrations and records versions. Tests use in-memory SQLite and verify indexes/triggers directly.

**Spec:** `SPEC/08-persistence-and-events.md` §3, §12.

## Global Constraints

- Standard-library `sqlite3`, explicit SQL, no ORM.
- Migrations are ordered, recorded, and re-runnable without duplicating schema.
- Partial unique indexes enforce one supervisor, one open direction, one running task per worker, one record per task, one claimed wake per agent.
- Events are append-only via SQLite triggers.
- Schema names/columns follow SPEC 08; no mutable JSON domain state.
- No old-code imports or old tests.
