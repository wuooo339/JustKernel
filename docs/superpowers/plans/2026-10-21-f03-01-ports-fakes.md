# F03-01 Ports and Deterministic Fakes Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Define application ports for repositories, messaging, runtime, tools, hardware, artifacts, and IDs, then provide deterministic in-memory fakes for application tests.

**Architecture:** `src/justkernel/application/ports.py` contains `Protocol` definitions importing domain types only. `src/justkernel/application/fakes.py` contains deterministic fakes with no I/O. Application services depend on these ports, never on platform adapters.

**Spec:** `SPEC/03-architecture.md` §3.1; `SPEC/11-testing-and-quality.md` §5.

## Global Constraints

- Application layer may import domain/shared; it must not import `justkernel.platform`.
- Fakes are deterministic: explicit clocks/counters, no sleeps, no network.
- Protocols use structural typing and are runtime-checkable where they contain methods only.
- Repository updates use optimistic expected versions.
- No old-code imports or old tests.

```python
class IdFactoryPort(Protocol):
    def cluster_id(self) -> ClusterId: ...
    def agent_id(self) -> AgentId: ...
    def direction_id(self) -> DirectionId: ...
    def task_id(self) -> TaskId: ...
    def candidate_id(self) -> CandidateId: ...
    def test_record_id(self) -> TestRecordId: ...
    def message_id(self) -> MessageId: ...
    def lease_id(self) -> LeaseId: ...
    def best_selection_id(self) -> BestSelectionId: ...
    def event_id(self) -> EventId: ...

class ClusterRepositoryPort(Protocol):
    def insert(self, cluster: Cluster) -> None: ...
    def update(self, cluster: Cluster, expected_version: int) -> int: ...
    def get(self, cluster_id: ClusterId) -> Cluster: ...
    def version(self, cluster_id: ClusterId) -> int: ...

class AgentRepositoryPort(Protocol): ...  # insert/update/get/version
class TaskRepositoryPort(Protocol): ...   # insert/update/get/version
class MessageBusPort(Protocol): ...       # publish/messages
class AgentRuntimePort(Protocol): ...     # create/start/send/close/cancel
class ToolBackendPort(Protocol): ...      # submit_test/submit_profile
class HardwareQueuePort(Protocol): ...    # acquire/release/status
class ArtifactStorePort(Protocol): ...    # put_bytes/get_bytes/verify/ref_for
```
