# F01-02 Execution Contracts Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Implement immutable, validated contracts for startup input, task feedback, budgets, evaluation, wake scheduling, and model routing.

**Architecture:** Pure dataclasses under `cluster/`, `task/`, `testing/`, `comm/`, and `agent/`. They depend on `shared` only (and domain-to-domain imports where cohesive). No platform or I/O imports. Digests use canonical JSON.

**Spec:** `SPEC/13-generation-and-iteration-contract.md` §1–3, §7, §9; `SPEC/04-domain-model.md` §3.

## Global Constraints

- Contracts are immutable (`frozen=True`, `slots=True`).
- `OperatorSpec` requires semantics, input contract, executable reference or oracle, accuracy policy, case pack, target, engineering policy, evaluation policy.
- Case pack subset must reference the full pack and a selection rule.
- `BudgetPolicy` needs at least one global hard cap among duration, tokens, cost, tool time, device time, or rounds. Bootstrap/plateau limits do not count.
- Performance target enabled implies `profiler_required=True`.
- `TaskContext` empty lists require `EmptyReason` entries.
- Artifact grants must match the context task id.
- No secrets or old-code dependencies.

## Interfaces

```python
class BudgetPolicy:
    max_duration_s: int | None
    max_tokens: int | None
    max_cost_usd: float | None
    max_tool_seconds: int | None
    max_device_seconds: int | None
    max_rounds: int | None
    max_bootstrap_attempts: int | None
    plateau_rounds: int = 5
    max_consecutive_failures: int = 3
    final_validation_reserve: int | None = None

class EvaluationPolicy:
    case_pack_digest: Digest
    reference_digest: Digest
    accuracy_policy_digest: Digest
    allowed_backends: tuple[str, ...]
    environment_fingerprint: str
    timing_unit: str
    warmup: int
    repeats: int
    aggregation: str
    aggregation_params: tuple[tuple[str, float], ...] = ()
    per_case_regression_limit: float | None = None
    min_improvement: float = 0.0
    performance_target_enabled: bool = False
    profiler_required: bool = False

class WakePolicy:
    wake_debounce_ms: int = 500
    summary_interval_s: int = 30
    wait_deadline_s: int = 300
    stalled_timeout_s: int = 60
    max_stalled_wakes: int = 1

class ModelRouting:
    system_default: str
    role_defaults: tuple[tuple[str, str], ...] = ()
    direction_defaults: tuple[tuple[str, str], ...] = ()
    allowed_fallbacks: tuple[str, ...] = ()
    provider_concurrency: tuple[tuple[str, int], ...] = ()
    price_source: str = "configured"
    def resolve(self, role, direction_id=None, task_profile=None, instance_profile=None) -> str: ...

class OperatorSpec:
    operator_id: str
    version: str
    semantics: str
    input_contract: str
    reference: ReferenceSpec
    accuracy_policy: AccuracyPolicy
    case_pack: CasePackRef
    target: TargetSpec
    engineering_policy: EngineeringPolicy
    evaluation_policy: EvaluationPolicy
    def digest(self) -> Digest: ...
    def to_ref(self, artifact_ref: str) -> OperatorRef: ...

class TaskContext:
    task_id: TaskId
    operator_spec_ref: OperatorRef
    base_candidate_ref: CandidateRef | None
    objective: str
    acceptance: tuple[str, ...]
    feedback: tuple[FeedbackRef, ...]
    history: tuple[HistoryEntry, ...]
    shared_evidence: tuple[SharedEvidence, ...]
    resource_grants: tuple[ArtifactGrant, ...]
    budget: TaskBudget
    empty_reasons: tuple[EmptyReason, ...] = ()
    def digest(self) -> Digest: ...
```
