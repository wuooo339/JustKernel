# F07-07 Web Views and Accessibility

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Render cluster/agents/board/tasks/candidates/records/hardware/report views as escaped, accessible HTML strings without a build step.

**Architecture:** `components/html.js` provides escaping/badges/sections; `views/*.js` consume state selectors and return HTML. PENDING and VALIDATED best are distinct; failed candidates and missing metrics remain visible.

**Spec:** `SPEC/09-api-and-frontend.md` §6.3–§6.5.

## Global Constraints

- No framework/build dependency.
- All dynamic text escaped.
- PENDING best is never labeled final BEST.
- Failed candidates remain visible.
- Unknown metrics use `—`.
- Accessible section/table/list structure and aria labels.
- Web modules ≤400 lines.
