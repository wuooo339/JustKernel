# F09-02 100-Agent Scale and Long Run

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Exercise 100 logical agents over multiple deterministic turns, then close workers and runtime sessions without orphan sessions or device leases.

**Architecture:** An e2e test combines domain `AgentService`, `AgentRuntimePool`, `CheckpointStore`, `WorkerLifecycle` and `AgentLeaseBook`. All time is logical; no model/device is used.

**Spec:** `SPEC/01-product-vision.md` §3; `SPEC/12-migration-and-acceptance.md` §4.

## Global Constraints

- Exactly 100 active agents; 101st rejected.
- 100 runtime sessions over multiple turn cycles.
- Worker close releases tracked leases.
- Shutdown leaves zero runtime sessions and zero leases.
- Checkpoints remain as recovery data.
- No sleeps, models or devices.
- No old-code imports/tests.
