# F08-02 CLI Modes and Configuration

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Add immutable app/config objects with CLI > env > .env precedence and expose cluster/demo/worker/migrate CLI modes.

**Architecture:** `platform/config.py` is the only env reader. `bootstrap/cli.py` uses argparse, applies CLI overrides, and dispatches modes. Migrate initializes the journal and runs `LegacyImporter`; other modes print resolved settings without launching models/devices.

**Spec:** `SPEC/10-configuration-security-observability.md` §1; `SPEC/12-migration-and-acceptance.md` §5.

## Global Constraints

- Config immutable; no directory creation in constructors.
- Mode must be one of cluster/demo/worker/migrate.
- CLI > environment > `.env` > defaults.
- No `AWORKER_*` compatibility branch.
- Migrate is explicit and read-only on old data.
- Invalid config exits nonzero without secrets.
