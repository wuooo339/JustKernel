# F07-04 A2A Cluster Gateway

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Add a per-cluster A2A card, read-only status, and restricted idempotent external messages that cannot target worker/board channels.

**Architecture:** Add `EXTERNAL` channel/message type and ACL resource. `routes_a2a.py` publishes human-authored external messages through the message bus and tracks delivery IDs in `ApiContext`.

**Spec:** `SPEC/09-api-and-frontend.md` §3.

## Global Constraints

- One cluster card, only cluster-status/cluster-message skills.
- No worker private channel or board write.
- `delivery_id` is idempotent.
- External sender is human, never an agent.
- No old-code imports/tests.
