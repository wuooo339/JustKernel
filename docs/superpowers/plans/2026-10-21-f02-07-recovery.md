# F02-07 Startup Recovery Matrix Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Implement the startup recovery matrix: interrupt running agents/tasks, pause running/converging clusters, reconcile leases with the global hardware ledger, and report pending outbox work without rerunning anything.

**Architecture:** `platform/persistence/recovery.py` runs one SQLite transaction over the journal. It optionally reconciles each journal lease with a `LeaseLedger` port (satisfied by `HardwareLedger`). No model turn, task, or test is automatically replayed.

**Spec:** `SPEC/08-persistence-and-events.md` §7; `SPEC/06-communication-and-orchestration.md` §10.

## Global Constraints

- Agent RUNNING → INTERRUPTED.
- Task ASSIGNED/RUNNING → INTERRUPTED (terminal), `finished_at=now`; never rerun.
- Cluster RUNNING/CONVERGING → PAUSED, preserving phase.
- Expired LEASED mirror → EXPIRED; active execution stays blocked in the global ledger.
- Missing/unknown global lease → quarantine device; never silently reassign.
- Pending outbox rows are reported, not deleted.
- Recovery is idempotent and does not append evidence.

## Interfaces

```python
class LeaseLedger(Protocol):
    def get_lease(self, lease_id: str) -> DeviceLease: ...
    def mark_expired(self, lease_id: str, now_ms: int) -> DeviceLease: ...
    def quarantine(self, device_id: str, reason: str, now_ms: int) -> None: ...

class RecoveryReport:
    agents_interrupted: int
    tasks_interrupted: int
    clusters_paused: int
    leases_expired: int
    devices_quarantined: int
    pending_outbox: int

def recover(connection, now_ms: int, ledger: LeaseLedger | None = None) -> RecoveryReport: ...
```
