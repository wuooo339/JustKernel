# F01-05 Task Aggregate Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Implement the Task aggregate with four kinds (`GENERATE`, `OPTIMIZE`, `TEST`, `PROFILE`), kind-specific candidate/skill constraints, and the task state machine.

**Architecture:** Pure domain modules under `src/justkernel/task/`. The aggregate is mutable with explicit transition guards; terminal states are irreversible. Cross-aggregate checks (worker belongs to mentor) remain application-level.

**Spec:** `SPEC/04-domain-model.md` §4.4; `SPEC/06-communication-and-orchestration.md` §7.

## Global Constraints

- `GENERATE` has no candidate and no skill.
- `OPTIMIZE` requires a candidate and has no skill.
- `TEST` and `PROFILE` require both a candidate and a skill.
- Task terminal states: `SUCCEEDED`, `FAILED`, `CANCELLED`, `INTERRUPTED`.
- Success requires a result reference; failure/cancel/interrupt require a reason.
- Retry uses a new TaskId and records `retry_of_task_id`.
- No old-code imports or old tests.

## Interfaces

```python
class TaskKind(StrEnum):
    GENERATE = "GENERATE"
    OPTIMIZE = "OPTIMIZE"
    TEST = "TEST"
    PROFILE = "PROFILE"

class TaskState(StrEnum):
    ASSIGNED = "ASSIGNED"
    RUNNING = "RUNNING"
    SUCCEEDED = "SUCCEEDED"
    FAILED = "FAILED"
    CANCELLED = "CANCELLED"
    INTERRUPTED = "INTERRUPTED"

class Task:
    id: TaskId
    cluster_id: ClusterId
    mentor_id: AgentId
    worker_id: AgentId
    kind: TaskKind
    direction_id: DirectionId
    operator_spec_ref: OperatorRef
    context_ref: str
    context_digest: Digest
    budget_ref: str
    objective: str
    created_at: int
    candidate_id: CandidateId | None = None
    skill_ref: SkillRef | None = None
    retry_of_task_id: TaskId | None = None
    constraints: tuple[str, ...] = ()
    state: TaskState = ASSIGNED
    result_ref: str | None = None
    finished_at: int | None = None
    terminal_reason: str | None = None

    def start(self) -> None: ...
    def succeed(self, result_ref: str, now_ms: int) -> None: ...
    def fail(self, reason: str, now_ms: int) -> None: ...
    def cancel(self, reason: str, now_ms: int) -> None: ...
    def interrupt(self, reason: str, now_ms: int) -> None: ...
```
