# F04-02 Runtime Runner, Checkpoints, and Agent Pool Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Implement a logical Agent runtime pool over an `AgentRunner` port, with process assignment, single-turn enforcement, model concurrency limits, JSON checkpoints, and explicit interrupt/resume behavior.

**Architecture:** `platform/runtime/runner.py` defines the runner request/result contract; `checkpoint.py` stores session JSON outside evidence artifacts; `pool.py` manages logical sessions/processes and calls the runner. No real model or device calls are made in this feature.

**Spec:** `SPEC/05-agent-runtime-and-skills.md` §2–3.

## Global Constraints

- Logical agents ≤ `max_agents`; runtime processes ≤ `runtime_processes`; concurrent model calls ≤ `model_concurrency`.
- One RUNNING turn per agent; RUNNING agents do not start another turn.
- Crash/interrupt marks RUNNING sessions INTERRUPTED; explicit resume uses a new session, never replays a turn.
- Checkpoints are recovery data, not evidence.
- Closed agents reject turns.
- No real model/network/device calls; no old-code imports/tests.

## Interfaces

```python
class AgentRunRequest:
    agent_id; cluster_id; role; model_profile; skills; mentor_id
    session_id; input; checkpoint: Mapping[str, object] | None

class RunnerResult:
    output: str
    checkpoint: Mapping[str, object] | None = None

class AgentRunner(Protocol):
    def run(self, request: AgentRunRequest) -> RunnerResult: ...

class CheckpointStore:
    def save(cluster_id, agent_id, session_id, payload) -> str: ...
    def load(cluster_id, agent_id, session_id) -> dict | None: ...
    def list_sessions(cluster_id, agent_id) -> tuple[str, ...]: ...

class RuntimeSession:  # mutable
    agent_id, cluster_id, role, model_profile, mentor_id,
    session_id, process_index, state, current_turn_id, checkpoint_ref

class AgentRuntimePool:
    def create_agent(...) -> RuntimeSession: ...
    def start_turn(agent_id, input) -> RunnerResult: ...
    def interrupt(agent_id, reason="interrupted") -> RuntimeSession: ...
    def interrupt_all(reason="control restart") -> int: ...
    def resume(agent_id, session_id) -> RuntimeSession: ...
    def close_agent(agent_id) -> RuntimeSession: ...
    def get(agent_id) -> RuntimeSession: ...
```
