# F07-02 API Read and Lifecycle Routes

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Expose DTO-only HTTP routes for cluster/agent/direction/task/tool-job/candidate/record/report/board/message/hardware read models, cluster commands and cluster creation, with object-level ACL for task context and tool jobs.

**Architecture:** `ApiContext` injects repositories and services. Route groups live under `platform/http/routes_*.py`; shared conversions/ACL live in `routes_common.py`. `POST /clusters` maps a validated `ClusterCreateBody` to `StartClusterRequest`.

**Spec:** `SPEC/09-api-and-frontend.md` §2, §4, §9.

## Global Constraints

- No DB rows/private paths in responses.
- Task context/tool-job reads require the correct agent identity.
- DTO fields are immutable and explicit.
- Cluster create/actions use existing application services and idempotency middleware.
- No domain imports of FastAPI.
- No old-code imports/tests.
