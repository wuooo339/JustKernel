# F06-03 Baseline Establishment and Bootstrap Budget

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Establish a cluster baseline only from a full executed TEST PASS, count bootstrap validation attempts, and stop with `baseline_not_established` when the bootstrap budget is exhausted.

**Architecture:** `BaselineService` composes cluster/candidate/TestRecord repositories with `BudgetPolicy.max_bootstrap_attempts`. It validates candidate ownership and full-pass evidence before updating the cluster.

**Spec:** `SPEC/13-generation-and-iteration-contract.md` §2, §7.

## Global Constraints

- A baseline requires `executed=true`, `coverage=FULL`, `outcome=PASS`, and TEST kind.
- Failed/audit/foreign-candidate evidence never establishes a baseline.
- `max_bootstrap_attempts` counts validation attempts; success at the limit still establishes.
- Exhaustion without a baseline stops the cluster with reason `baseline_not_established`.
- The first baseline is immutable; a second attempt is rejected.
- No old-code imports/tests.
