# F03-05 ToolJob and TestRecord Sealing Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Implement application use cases for submitting TEST/PROFILE ToolJobs idempotently and sealing immutable TestRecords (including audit records).

**Architecture:** `application/testing_service.py` depends on task/agent/test-record/tool-job repository ports and `ToolBackendPort`. A ToolJob is keyed by task; duplicate submissions with the same request return the existing job, conflicting requests are rejected. Sealed TestRecords are append-only and one task has at most one terminal record.

**Spec:** `SPEC/13-generation-and-iteration-contract.md` §5; `SPEC/07-testing-and-profile.md` §3; `SPEC/08-persistence-and-events.md` §6.

## Global Constraints

- One Task has at most one ToolJob and one terminal TestRecord.
- submit_test/submit_profile require the matching task kind and worker role.
- Same task + same request is idempotent; conflicting parameters raise.
- TestRecord is immutable; sealing is append-only.
- Executed record requires task/job; audit record has no task/job and is executed=false.
- Application imports ports/domain only, never platform.
- No old-code imports or old tests.

## Interfaces

```python
class ToolJobState(StrEnum): QUEUED; RUNNING; SUCCEEDED; FAILED; CANCELLED; INTERRUPTED
class ToolJob:  # frozen
    id: str; task_id: TaskId; candidate_id: CandidateId
    request_digest: Digest; state: ToolJobState
    record_id: str | None; error: str | None; created_at: int

class TestingService:
    def submit_test(self, *, task_id, case_selection, timeout_s, device=None) -> ToolJob: ...
    def submit_profile(self, *, task_id, case_selection, timeout_s, device=None) -> ToolJob: ...
    def seal_record(self, *, task_id, outcome, coverage, artifact, environment,
                    backend, created_at, summary="") -> TestRecord: ...
    def seal_audit(self, *, candidate_id, kind, skill_ref, outcome, audit_id,
                   artifact, environment, created_at, summary="") -> TestRecord: ...
```
