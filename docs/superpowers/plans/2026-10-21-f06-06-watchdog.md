# F06-06 Watchdog, Stall Detection and Pause

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Detect a RUNNING cluster with no active tasks, turns, pending wakes or valid WAIT; wake the supervisor once, then pause the cluster on repeated inactivity.

**Architecture:** `WatchdogService` consumes an explicit `ClusterActivity` snapshot and `WakePolicy`. It tracks consecutive stall checks per cluster; activity resets the counter. First stall yields a `CLUSTER_STALLED` action, the next exhausts `max_stalled_wakes` and pauses through `ClusterService`.

**Spec:** `SPEC/13-generation-and-iteration-contract.md` §4.8.

## Global Constraints

- Only RUNNING clusters are checked.
- Any active task/turn/pending wake/valid WAIT means not stalled.
- First stall wakes supervisor once; repeated inactivity pauses.
- PAUSED/terminal clusters are untouched.
- Explicit `now_ms`; no sleeps.
- No old-code imports/tests.
