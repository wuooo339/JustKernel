# F07-08 Demo and Replay Fixture

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Provide a deterministic synthetic event fixture that replays through the same web reducer to a completed cluster with a validated best and a visible failed candidate, with zero model/device calls.

**Architecture:** `web/demo/fixture.json` is the source of truth; `fixture.js` imports it and exports `DEMO_EVENTS`, `DEMO_META`, `DEMO_STATE`. Node tests assert state/views; Python e2e validates the fixture and invokes the JS replay.

**Spec:** `SPEC/09-api-and-frontend.md` §6; `SPEC/11-testing-and-quality.md`.

## Global Constraints

- Fully synthetic: `model_calls=0`, `device_calls=0`.
- Event sequences are contiguous and IDs unique.
- Same web reducer handles demo replay.
- Failed candidate remains visible; best is VALIDATED.
- No model/device/network use.
- No old-code imports/tests.
