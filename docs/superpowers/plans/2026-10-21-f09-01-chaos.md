**Goal:** Exercise crash/recovery paths with real process kill, device-ledger loss and disk-full rollback, proving interrupted state and quarantine/rollback behavior without automatic replay.

**Architecture:** Add chaos tests around the existing `recover()` matrix and hardware ledger. A subprocess opens the journal and is SIGKILLed; recovery runs on the same file. A failing connection simulates disk-full rollback. A missing global lease triggers device quarantine.

## Global Constraints

- No real model, device or network.
- No automatic rerun of interrupted work.
- Disk-full failure rolls back journal changes.
- Missing lease quarantines the device.
- POSIX kill test skips Windows.
- No old-code imports/tests.
