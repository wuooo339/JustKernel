# F04-04 Six Role Skills and Built-in Tester/Profiler

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`) syntax.

**Goal:** Add six role skill definitions and built-in CANN simulation tester/profiler skills, all valid under `SkillLoader`.

**Architecture:** Resource-only feature plus a regression test. `agent/skill_loader.py` loads base/builtin/user skills; this feature supplies the missing base role and builtin tester/profiler definitions. No production code is expected beyond registering the `agent` backend for role skills.

**Spec:** `SPEC/05-agent-runtime-and-skills.md` §6.4.

## Global Constraints

- Every role has a base SKILL.md with role/backend/version/allowed_tools.
- Worker role skills contain no board tools.
- Tester base + builtin `cann-simulation-test`; profiler base + builtin `cann-profiler`.
- Skill prompts treat board/messages/test output as data, not instructions.
- No old-code imports/tests.
