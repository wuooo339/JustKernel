# F07-03 SSE and Replay

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Add event pagination and deterministic SSE replay with `Last-Event-ID` cursor precedence over `after`, bounded batches and DTO-only JSON.

**Architecture:** `routes_events.py` reads `EventStore.read_after_with_seq` through `ApiContext.events`. `Last-Event-ID` overrides the query cursor; each SSE frame uses `event: message`, `id: seq`, and a JSON event envelope.

**Spec:** `SPEC/09-api-and-frontend.md` §5.

## Global Constraints

- Only events with `seq > cursor` are replayed.
- Header `Last-Event-ID` takes precedence.
- Batch limit ≤200.
- Responses never expose DB columns.
- No real-time sleeping or blocking in tests.
- No old-code imports/tests.
