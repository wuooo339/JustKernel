# F05-04 CANN Simulation Backend and Fake Runner

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox (`[ ]`).

**Goal:** Add a CANN simulation backend contract that validates test/profile submissions, captures immutable requests, and executes through an injectable runner; provide a deterministic fake runner and stable environment fingerprint.

**Architecture:** `platform/tools/cann_simulation.py` implements `ToolBackendPort` without real devices. `CannEnvironment` fingerprints the simulator/toolchain; `CannSimulationBackend` stores queued requests and executes them via a `CannRunner`; `FakeCannRunner` is deterministic for adapter tests.

**Spec:** `SPEC/07-testing-and-profile.md` §4; `SPEC/13-generation-and-iteration-contract.md` §5.

## Global Constraints

- No subprocess, device, or real CANN dependency in tests.
- Empty case selection and non-positive timeout are rejected.
- Environment fingerprint is stable for equal values and changes for device/toolchain changes.
- Metrics are finite and carry unit/direction.
- Execution results bind to the exact submitted request.
- No old-code imports/tests.
